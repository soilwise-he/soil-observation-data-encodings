## SoilVoc

Soil vocabulary is a collection of terms relevant in soil sciences, to facilitate annotation metadata with relevant terms, as well as annotate dataset (columns) with relevant soil properties and procedures.

The content of soil vocabulary is managed in the git repository <https://github.com/soilwise-he/soil-vocabs/>.

[SKOS](https://www.w3.org/2004/02/skos/) is used as an underlying ontology to organize the concepts. The SKOS ontology has been extended to capture a relationship between soil properties and soil observation procedures.

### Identifiers and proxy

The identifiers of SoilVoc are constructed through w3id at <https://w3id.org/EUSoilVoc>

W3id facilitates detection of the client, if a human browser is identified, the user is forwarded to a web application at https://soilwise-he.github.io/soil-vocabs/, else the user is forwarded to the rdf content.

We've looked at various webbased skos interfaces, finally we decided to develop a dedicated UI.
