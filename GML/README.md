# Sharing Soil Observation data via a GML encoding

The state of technology when the first O&M practices were described was the use of
XML based web services. OGC, ISO and INSPIRE initially selected the GML encoding 
to express their data sharing models. 

Unfortunately the XML technology was not widely adopted and more agile technologies emerged such as GeoPackage and SensorThings API. But it is still important to be aware of the GML encodings: 
  - Various datasets are available on the web in the GML encoding.
  - Documentation about the soil datamodels often refers primarily to the GML encoding.

The EJP Soil project described the GML encodings for soil quite extensively in their [soil data assimilation cookbook](https://ejpsoil.github.io/soildata-assimilation-guidance). Topics such as Hosting data over WFS, Loading data and transforming data are covered in the cookbook.
